### Glad to see you here!

I build game engines from scratch and I'm a full-stack developer. 🚀

Right now most of my time goes into **Roblox**: an engine layer written in Luau (ECS, networking, performance tooling) and the games built on top of it, from a creature-raising fighting tycoon to a superhero prototype with flight, constructs and time-slow powers.

I like owning the whole stack: engine code, gameplay, 3D assets in Blender, and the web services around it.
